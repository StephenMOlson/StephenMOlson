---

## 🧠 Engineering Philosophy

* **Explicit Over Implicit:** I heavily lean toward lightweight tools like Dapper and raw SQL over heavy, black-box ORMs. If an application is interacting with a relational database, the developer should have absolute creative control over the queries hitting the wire.
* **Strict Boundaries:** I build systems using Clean Architecture principles to ensure core business rules remain isolated, testable, and entirely insulated from shifting UI frameworks or third-party infrastructure.
* **Built-in Resilience:** Modern cloud environments are transient by nature. I focus on baking automated fault tolerance, retry patterns, and transactional safety directly into the network and data tiers rather than treating stability as an afterthought.
